# Data Dictionary — Careem Quik synthetic supply-chain dataset

> **ILLUSTRATIVE SYNTHETIC DATA.** Generated by `src/generate_dummy_data.py`
> (seed 20260802). No Careem data of any kind was used. Figures are for
> demonstrating analytical method only and are not representative of any real
> business.

**Scope:** 8 dark stores · UAE (Dubai, Abu Dhabi, Sharjah) · 266 SKUs · 8 suppliers
**Period:** 2025-01-01 → 2026-06-30 (546 days, daily grain)
**Currency:** AED (USD conversion at the 3.6725 peg)

## `inventory_daily.csv` — 737,100 rows · store × SKU × day

The core operational fact table.

| Column | Type | Description |
|--------|------|-------------|
| date | date | |
| store_id | str | FK |
| sku_id | str | FK |
| opening_units | int | Stock at start of day |
| received_units | int | Units received from suppliers that day |
| sold_units | int | Units actually sold |
| wasted_units | int | Units expired and written off (FEFO) |
| closing_units | int | Stock at end of day |
| lost_demand_units | int | Demand that arrived but could not be served |
| stockout_flag | 0/1 | 1 if any demand went unserved that day |
| ordered_units | int | Units ordered on that day's replenishment review |

**Fill rate** = `sold_units / (sold_units + lost_demand_units)`
**Waste rate** = `wasted_units / received_units`

## `purchase_orders.csv` — ~123k rows · one per PO line

| Column | Type | Description |
|--------|------|-------------|
| po_id | str | Primary key |
| supplier_id, store_id, sku_id | str | FKs |
| order_date | date | When the order was raised |
| promised_date | date | order_date + contracted lead time |
| received_date | date | When it actually landed |
| qty_ordered | int | |
| qty_received | int | Short shipments are real; compare to ordered |
| unit_cost_aed | float | |
| po_value_aed | float | qty_ordered × unit_cost |

**Actual lead time** = `received_date − order_date`
**On-time** = `received_date ≤ promised_date` · **In-full** = `qty_received ≥ qty_ordered`
